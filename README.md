How to Run the UL Campus Navigation Project

Follow these steps to run the project on your computer:

Step 1: Extract the ZIP file

Download the project ZIP file.
Right-click the ZIP file and select Extract All.
Open the extracted project folder.

Step 2: Open Command Prompt

Open Command Prompt (CMD).
Navigate to the frontend folder using the project path:
cd "C:\Users\27761\Downloads\ul-campus-nav (4)\ul-campus-nav\frontend"

Press Enter.

Step 3: Install the project dependencies

Type:

npm install
Press Enter.
Wait for the installation to finish. This may take a few minutes.

Step 4: Start the project

Once npm install has finished, type:

npm run dev
Press Enter.
Wait for the development server to start.

Step 5: Open the project in your browser

After running npm run dev, you should see something similar to:

Local: http://localhost:5173/
Copy the Local address shown in your Command Prompt.
Open your web browser.
Paste the address into the browser's address bar.
Press Enter.

The UL Campus Navigation website should now open.

Important: Keep the Command Prompt window running while using the website. To stop the project, go back to Command Prompt and press Ctrl + C.```
